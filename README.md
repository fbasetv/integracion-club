# Integrar FBASE.Tv en tu club

Guía para los clubes, temporada 2026/27: https://fbasetv.github.io/integracion-club/

Se publica con GitHub Pages desde la rama `main`.

## Cómo actualizarla

El original es `procesos/landing-integracion.html`, en el repositorio `Claude-Team-base-comun`.
Aquí no se edita a mano.

`index.html` son las primeras líneas de este repositorio (hasta el comentario «A partir de aquí»,
con el idioma, el tamaño en el móvil, la vista previa para WhatsApp y el icono) más la copia literal
del original. Para publicar una versión nueva, se sustituye todo lo que va después de ese comentario
por el original actualizado, y se hace commit y push.

- `og.png`: imagen de la vista previa al compartir el enlace.
- `favicon.png`: icono de la pestaña.
